# Changelog

## 2026.10.07.1
- New: Compendium Builder. Builds world compendiums from the D&D Beyond books you own.
- One pack per book, per type: Monsters, Spells, Items, and Classes & Feats.
- Reads your own logged-in D&D Beyond tab with a console script. No token is saved.
- Content you do not own is skipped automatically.
- New menu in module settings: "Build Compendiums From My Books".

## 2026.09.29.01
- First GitHub release.
- Added manifest and download links, LICENSE, and this changelog.
- Earlier builds (up to 2026.09.27.15) were shared by zip.
